Politique de confidentialité

Comment BlockDirect traite les données lorsque vous utilisez les applications Windows et Android.

1. Principe

BlockDirect est conçu comme une application cliente pour Windows et Android. Le site de présentation peut être hébergé comme un site statique et n'a pas besoin de recevoir vos identifiants ÉcoleDirecte.

2. Données traitées par l'application

Pour afficher les informations du compte, l'application communique avec les services ÉcoleDirecte. Selon les fonctions utilisées, elle peut traiter localement des données telles que l'emploi du temps, les devoirs, les notes, la vie scolaire, les messages et d'autres informations fournies par ÉcoleDirecte.

3. Stockage local

Certaines données peuvent être conservées sur l'appareil afin d'améliorer les performances et, sur Android, permettre certaines fonctions hors connexion. Les éléments de session nécessaires à l'authentification sont également conservés localement selon la plateforme.

4. Serveur BlockDirect

La distribution Windows/Android visée par ce site ne nécessite pas de serveur central BlockDirect destiné à conserver les comptes ÉcoleDirecte des utilisateurs. Le backend de la version Windows s'exécute localement sur l'ordinateur.

5. Site web

Cette version du site n'intègre volontairement ni compte utilisateur, ni outil publicitaire, ni traqueur tiers. Si vous ajoutez plus tard un service d'analytique, un formulaire ou un hébergeur collectant des journaux, cette politique devra être mise à jour.

6. Suppression des données

Les données locales peuvent être supprimées en désinstallant l'application et, selon la plateforme, en effaçant les données de l'application. Des contrôles internes peuvent aussi permettre de supprimer le cache et la session.
